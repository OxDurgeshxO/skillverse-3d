# Skillverse 3D

Interactive 3D galaxy visualization of technical skills and architectural domains built with **Three.js** and modern WebGL.

🔗 **Live Demo:** [https://oxdurgeshxo.github.io/skillverse-3d/](https://oxdurgeshxo.github.io/skillverse-3d/)

---

## Features
- **3D Interactive Orbit Controls:** Explore tech skill clusters in immersive 3D space.
- **Dynamic Particle Shader Effects:** Glow nodes and connecting constellations.
- **Responsive WebGL Canvas:** Optimized for standard and retina displays.
- **Automated Deployment:** Continuous deployment via GitHub Actions (`deploy-pages.yml`).

---

## Tech Stack
- **Three.js** (WebGL 3D engine)
- **Vite** (Build tool)
- **GitHub Pages** (Hosting & CI/CD)

---

## Getting Started

### Prerequisites
- Node.js >= 18.0.0
- npm or pnpm

### Installation
```bash
git clone https://github.com/OxDurgeshxO/skillverse-3d.git
cd skillverse-3d
npm install
npm run dev
```

### Build
```bash
npm run build
```
